Clip Maker Privacy Policy

Clip Maker is a personal tool run by the owner of the YouTube channel Syntax Op, for that channel only.

Google data it uses

With the owner's permission, the tool uses the YouTube Data API to read the signed-in channel's basic details and to upload videos to that channel. It does not access any other person's account.

How the data is stored and shared

The sign-in token is stored only on the owner's own devices. Clip Maker has no server and does not sell or share Google user data. Finished public streams may be sent to Google's Gemini API to find highlights.

How to remove access

Access can be removed at any time from Google Account permissions.

Contact

Questions can be sent through the Syntax Op YouTube channel.
